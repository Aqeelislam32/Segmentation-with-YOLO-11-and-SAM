# Segmentation-with-YOLO-11-and-SAM

🧵 Tumor Detection using YOLOv11 & SAM – End-to-End Deep Learning Project

1️⃣ Project Title:
🔬 Automated Brain Tumor Detection using YOLOv11 & SAM for Medical Imaging

2️⃣ Project Work:
🚀 Trained a custom YOLOv11 model (yolo11n.pt) on a brain tumor dataset (glioma, meningioma, pituitary tumors).
📍 Used a detailed data.yaml config to define the dataset and classes.
🧠 Enhanced YOLO's object detection results by integrating Meta AI's SAM (Segment Anything Model) for precise segmentation.

3️⃣ Key Features:
✅ YOLOv8 for fast, real-time object detection.
✅ SAM for fine-grained segmentation on YOLO-predicted bounding boxes.
📸 Image-level predictions and masks are saved and visualized.
⚙️ GPU-accelerated training and inference for high performance.

4️⃣ Conclusion:
💡 This fusion of detection (YOLOv8) and segmentation (SAM) shows great potential for clinical decision support tools.
